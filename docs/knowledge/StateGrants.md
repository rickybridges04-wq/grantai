# StateGrants

**Status:** Draft — awaiting first sweep
**Phase:** 3 — Knowledge Base
**Category:** State

## Purpose

Holds state grant opportunity records, using the Opportunity Record Schema
defined in `GrantKnowledge.md`. Given BHI's Indiana/Michiana service area,
this file should prioritize Indiana state programs, but the schema supports
any state if GrantAI is later extended to other portfolio businesses
operating elsewhere.

## Notes

- State programs often move faster and have lighter compliance overhead
  than federal ones — good candidates for an early proof-of-concept run of
  the full Hunter → Writer → Reviewer pipeline
